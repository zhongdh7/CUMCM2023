# 2023 年全国大学生数学建模竞赛 C 题 —— 蔬菜类商品的自动定价与补货决策

本仓库是 **2023 年高教社杯全国大学生数学建模竞赛（CUMCM）C 题** 的建模工程，包含赛题数据、问题一的求解代码、结果图表，以及一份符合竞赛格式规范的论文 LaTeX 模板。

> 说明：目录名中的「模拟」表示本工程为备赛/练习性质，代码与论文模板可作为正式参赛的脚手架复用。

---

## 一、赛题背景

在生鲜商超中，蔬菜类商品保鲜期短、品相随销售时间变差，大部分品种「当日未售出、隔日无法再售」，因此商超需根据历史销售与需求情况**每天补货**。由于进货交易时间通常在凌晨 3:00–4:00，商家须在不确切知道具体单品和进货价格的情况下，提前做出当日各蔬菜品类的补货决策。

定价上，蔬菜通常采用 **「成本加成定价」** 方法，对运损、品相变差的商品打折销售。可靠的市场需求分析，对补货与定价决策都至关重要。

## 二、赛题要求（共 4 问）

| 问题 | 内容 |
|------|------|
| **问题 1** | 分析蔬菜**各品类及单品**销售量的分布规律及相互关系 |
| **问题 2** | 以**品类**为单位补货：分析各品类销售总量与成本加成定价的关系，给出未来一周（2023-07-01 ~ 07-07）的**日补货总量**与**定价策略**，使收益最大 |
| **问题 3** | 制定**单品**补货计划：可售单品总数控制在 **27–33** 个、单品订购量满足最小陈列量 **2.5 kg**，给出 7 月 1 日的单品补货量与定价策略 |
| **问题 4** | 为更好制定补货与定价决策，还需要采集哪些数据？说明意见与理由 |

本工程目前完成了 **问题 1** 的代码实现（见下文），问题 2–4 待建模求解。

## 七、问题一的实现逻辑（`problem1.py`）

问题一分为**数据预处理**和**相关性分析**两步，分别对应两个函数：

### 1. `data_preprocessing()`

1. 读取 `附件1.xlsx`（商品信息）与 `附件2.csv`（销售流水）；
2. 以 `单品编码` 为键做左连接（`pd.merge(..., how='left')`），把销售记录挂到对应商品上；
3. 用 `pivot_table` 将数据透视成 **「销售日期 × 分类名称」** 的二维表，单元格为该品类当日的销量总和（`aggfunc=np.sum`）；
4. 结果写入 `data/problem1_每个种类每日销量表.xlsx`，作为相关性分析的输入。

> 该步骤的核心目的：把逐条销售流水聚合为「每个品类、每天」的日销量序列，为后续计算品类之间的销量相关性做准备。

### 2. `relation_analyze(data)`

1. 绘制 **1×2** 的热力图，左图展示**皮尔逊相关系数**（`data.corr()`），右图展示**斯皮尔曼相关系数**（`data.corr(method='spearman')`），颜色映射 `coolwarm`，并标注数值；
2. 图表以 400 dpi 同时保存为 `figure/相关系数热力图.jpg` 与 `figure/相关系数热力图.pdf`；
3. 支持**交互式假设检验**：运行后按提示输入两个品类名称（空格分隔），脚本对这两个品类的日销量序列分别做皮尔逊与斯皮尔曼检验（`scipy.stats.pearsonr` / `spearmanr`），输出相关系数与 **p 值**，用于判断相关关系是否显著。

**方法论说明**：
- **皮尔逊相关系数**衡量变量间的**线性**相关程度，要求数据近似正态、线性；
- **斯皮尔曼相关系数**基于秩次，衡量**单调**相关关系，对异常值、非线性关系更稳健；
- 两者结合、辅以显著性检验（p 值），可更可靠地刻画不同蔬菜品类销量之间的关联。

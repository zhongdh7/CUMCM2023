# 全国大学生数学建模竞赛论文 LaTeX 模板

依据《全国大学生数学建模竞赛论文格式规范》（2025 年修订稿，来自报名承诺书附件），并参照 2023 年国赛 C 题论文排版整理。

## 文件说明

- `main.tex` —— 论文模板主文件（唯一需要编辑的文件）
- `main.pdf` —— 编译生成的示例 PDF（已生成，可直接查看效果）

## 如何编译

**务必使用 XeLaTeX 编译**（中文支持最好）：

- 命令行（在 Git Bash 中）：
  ```bash
  xelatex main.tex   # 需执行两次，以生成交叉引用
  ```
- VS Code（LaTeX Workshop）/ TeXstudio：将编译引擎设为 `xelatex`。

## 需要替换的占位内容

| 位置 | 需要修改的内容 |
|------|----------------|
| 摘要页标题 | `论文标题（请替换为您的论文题目）` |
| 摘要正文 | 按问题一/二/三概括模型与结论 |
| 关键词 | `关键词一；关键词二；…` |
| 问题重述 | 复述赛题背景与问题 |
| 模型假设、符号说明 | 按实际模型修改 |
| 各表格/图片 | 替换为真实数据、图表（图片用 `\includegraphics{文件名}`） |
| 附录代码 | 替换为你的可运行源程序 |

## 已满足的格式规范要点

- ✅ A4 纸，四边页边距 2.5cm（规范要求 ≥2.5cm）
- ✅ 电子版第一页为「摘要专用页」，不含承诺书、编号页、身份信息
- ✅ 摘要不超过一页；页码从摘要页起，位于页脚中部，阿拉伯数字从 1 连续编号
- ✅ 无目录；正文尽量控制在 20 页内，附录页数不限
- ✅ 表标题在表上方（表 N …）、图标题在图下方（图 N …），三线表
- ✅ 参考文献按 GB/T 7714 格式列出
- ✅ 附录包含支撑材料文件列表与源程序代码

## 注意事项

- **严禁**在摘要页、正文、附录任何位置出现学校、姓名、队号等身份信息。
- 若论文确实没有用到程序，需在附录注明「本论文没有用到程序」。
- 中文标题编号默认为「一、问题重述 / 2.1 / 5.1.1」；如需无编号标题，删除 `\section{}` 里的自动编号即可（改用 `\section*{}`）。
